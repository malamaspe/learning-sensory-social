# learning-sensory-social

Εικόνες, βίντεο και πρόγραμμα (`queue.json`) για τις αυτόματες δημοσιεύσεις στο Instagram και στη σελίδα Facebook του **Learning & Sensory Ωραιόκαστρο**.

Το repo είναι δημόσιο, γιατί το Instagram Graph API κατεβάζει τα αρχεία από δημόσιο link τη στιγμή της δημοσίευσης. Εδώ μπαίνει μόνο περιεχόμενο που έχει ήδη εγκριθεί, χωρίς metadata (EXIF/τοποθεσία), με θολωμένα πρόσωπα και ονόματα παιδιών.

Είναι ανεξάρτητο από κάθε άλλο repo, Sheet ή εφαρμογή.

_Οδηγίες εγκατάστασης: σε εξέλιξη._
